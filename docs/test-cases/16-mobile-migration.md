## Device and staging run sheet

Record build, device/OS, tester/date, pass/fail, and API request reference for each failure. Do not use a live client: every check is permanent.

- [ ] QR-only scan and torch on Android/iOS; permissions denied/granted via settings; no QR link opens.
- [ ] Hold one QR still; remove/re-present it; scan another product; verify inline feedback and repeat behavior against the real backend.
- [ ] Scan a larger session, check responsive list/counters, switch apps/lock/unlock, and verify no background submissions.
- [ ] Kill the process without using Back, relaunch, reopen scanner mode, and compare recovered summary/pages with portal records. Repeat after backend idle expiry.
- [ ] Both toolbar/OS back leave immediately on a slow end request; a subsequent entry uses a fresh UUID.
