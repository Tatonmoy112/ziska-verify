**How the look is tested.** An assertion test checks a rule in code (a colour is the token, a button is 56 high, a label is upper case). A golden test compares a picture of the component or screen with the approved one, pixel by pixel, and fails on any visual change; a person looks at a new or changed golden before it is kept.

## B. Components

Every variant and state of each component: assertions on its rules and a golden of its look. TC-UI-026 … -074.

A component is drawn as a screen places it: in a column inside the 24 px side padding (the header at the top of a list), 390 wide and as high as the component needs. Each case runs twice: its assertions alone (CI too) and with its goldens (tag `golden`). A golden waits for animations to end (a focus border, a spinner's arc) before it is taken. Flutter tests draw shadows as a solid dark outline: the black ring around a snack bar or a floating button in a golden is not in the app.
